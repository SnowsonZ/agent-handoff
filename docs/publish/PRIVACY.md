# 隐私政策

最后更新：2026-08-31

Agent Handoff 是一个在用户明确请求后运行的本地 Skill。它不提供远程服务，不包含遥测，不把仓库内容、任务棒、凭据或使用数据发送给发布者。

## 本地访问

为安装或更新 handoff 协议，Skill 会在用户指定的 git 仓库中读取和写入协议文件，并读取 git 元数据。具体目标文件会在执行前由安装器输出，用户应在授权写入前审查目标仓库。

## 网络与第三方

Skill 自身不发起网络请求。用户从插件市场、GitHub 或其它注册表下载和更新 Skill 时，相应平台会按其自身隐私政策处理账号、下载和安全扫描数据。

## 数据保存

发布者不接收或保存用户数据。安装结果和任务状态仅保存在用户自己的仓库和 git 历史中。

## 联系方式

隐私问题可通过 GitHub Issues 或 `snowsonz@outlook.com` 联系发布者。
